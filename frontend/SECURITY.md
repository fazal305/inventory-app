# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to **fazalabbas2002@gmail.com**. Don't open a public issue.

Include:

- what you found and where (endpoint, file or page)
- steps to reproduce, or a proof of concept
- the impact you think it has

You'll get an acknowledgement within 3 working days. Fixes are prioritised by severity, and you'll be credited in the fix if you'd like to be.

## Scope

In scope: the code in this repository (`server/`, `client/`).
Out of scope: the `legacy/` directory, which is kept only as a historical reference and is known to be insecure (plain-text passwords, string-built SQL). Never deploy it.

## Supported versions

Only the latest commit on the default branch is supported.
